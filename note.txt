# BUG - Import Completes Immediately (Imported: 0, Failed: 0)

## Problem

After:
- Paste structured text
- Preview (Validation successful)
- Start Import

The application immediately shows:

Import Completed
Imported: 0
Failed: 0
Duration: 0s

No automation starts.

## Investigate

Trace the complete execution flow:

Structured Text
    ↓
StructuredTextParser.parse()
    ↓
Invoice object
    ↓
Preview
    ↓
Start Import
    ↓
PurchaseAutomation.run(invoice)
    ↓
fill_header()
    ↓
fill_items()

Determine exactly where execution stops.

## Verify

1. How many items exist in invoice.items immediately after parsing?
2. How many items are passed into PurchaseAutomation.run()?
3. Is fill_header() being called?
4. Is fill_items() being called?
5. Is there any early return when invoice.items is empty?
6. Is Start Import accidentally creating a new empty Invoice instead of using the parsed Invoice?

## Add Temporary Logging

Print logs like:

Invoice parsed: X items
Invoice passed to automation: X items
Automation started
Filling header...
Filling items...
Entering item 1
Entering item 2
...
Automation finished

## Expected

For the provided invoice:

Invoice parsed: 6 items
Invoice passed to automation: 6 items
Automation started
Header entered
Entering item 1
Entering item 2
...
Entering item 6
Automation complete

## Goal

Identify and fix the reason why automation exits immediately with:

Imported: 0
Failed: 0

Do not modify:
- GUI
- Parser format
- Validation
- Preview
- Automation workflow

Only fix the underlying cause and remove the premature exit.

## Deliverables

- Files modified
- Root cause
- What was fixed
- Confirmation that automation now processes all parsed items correctly.

==================================================
ISSUES FOUND
==================================================

1. main.py did not start the actual GUI application.
   - Impact: A fresh Windows install following README instructions would run main.py and only print a startup message.
   - Severity: Production readiness bug.

2. README.md was stale.
   - Impact: It described only a base project scaffold and did not document the actual GUI, JSON support, verification command, or current configuration points.
   - Severity: Production readiness/documentation bug.

3. requirements.txt contained unused packages.
   - Removed unused dependencies: keyboard, mouse, opencv-python, pyperclip, psutil.
   - Impact: Fresh installs would request unnecessary packages and permissions/surface area.
   - Severity: Maintainability/security hygiene issue.

4. JSON parser only accepted invoice fields at the root object.
   - Impact: Common API output such as {"invoice": {...}} would fail validation even though it is a reasonable production JSON shape.
   - Severity: Correctness/robustness issue.

5. JSON item list key normalization was incomplete.
   - Impact: "medicine_list" normalizes to "medicine list", but the accepted list keys did not include that normalized spelling.
   - Severity: Correctness issue.
